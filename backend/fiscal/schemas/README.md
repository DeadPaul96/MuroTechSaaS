# Esquemas XSD MH v4.4

Descargar antes de validar en producción:

```bash
cd backend
python scripts/download_xsd_schemas.py
```

Origen oficial: `https://cdn.comprobanteselectronicos.go.cr/xml-schemas/v4.4/`

Con `HACIENDA_XSD_AUTO_DOWNLOAD=true` (default) el backend puede descargar el XSD principal en la primera emisión.
